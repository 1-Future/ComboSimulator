ComboSim API

Static JSON API for accessing champion and combo data. No authentication required.

Endpoints

GET /data/champions.json

Returns all 150 champions with metadata.

{
  "version": "1.0.0",
  "champions": [
    {
      "id": "yasuo",
      "name": "Yasuo",
      "title": "The Unforgiven",
      "roles": ["fighter", "assassin"],
      "difficulty": 3,
      "comboCount": 11,
      "portrait": "https://cdn.communitydragon.org/latest/champion/157/portrait",
      "splash": "https://cdn.communitydragon.org/latest/champion/157/splash-art",
      "tags": ["animation-cancel", "keyblade"]
    }
  ]
}

GET /data/combos/{championId}.json

Returns all combos for a champion with timing data.

Example: /data/combos/yasuo.json

{
  "championId": "yasuo",
  "patch": "14.24",
  "lastVerified": "2026-03-14",
  "combos": [
    {
      "id": "yasuo-e-q-aa-e",
      "name": "Yasuo E Q AA E",
      "description": "Yasuo: E → AA → Q → AA → E",
      "difficulty": "intermediate",
      "video": {
        "filename": "Yasuo/Yasuo E  Q  AA  E.mp4",
        "duration": 6.0,
        "fps": 60,
        "comboStart": 1.7
      },
      "inputs": [
        { "key": "E", "time": 1.7, "label": "E", "window": 100, "action": "spell3" },
        { "key": "A", "time": 2.2, "label": "AA", "window": 100, "action": "autoattack" }
      ]
    }
  ]
}
