Welcome to Combo Simulator!

Here's how to use it:

  • 🎥 Load a video using the file input.

  • 🔈 Toggle ping sound with the 🔈 button.
  • 🔓 Lock or unlock editing mode with 🔓/🔒 button.
  • 📂 Save or load combos as JSON.
  • 🔄 Reset combo with your assigned key.
  • 🎯 Use ← and → arrow keys to move video frame-by-frame for precise timing.
  • 🖱️ **Left-click a combo input to change its hotkey**.
  • 🖱️ **Right-click a combo input to delete it**.
  • 🔎 Use Ctrl + and Ctrl - (or pinch zoom) to adjust page size.
